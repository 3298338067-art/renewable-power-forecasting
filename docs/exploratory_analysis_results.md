# 输入消融与统一探索性评估

## 1. 分析定位

本轮分析在普通 LSTM、XGBoost 和 Attention-LSTM 的正式测试结果已经查看后开展，因此全部新增消融、分组诊断和区间估计均标记为 **post-hoc exploratory analysis**。它们用于解释现有模型行为，不重新选择主模型，也不构成预注册或确认性证据。

所有时间戳和日期块使用 UTC。普通 LSTM 的完整输入结果直接复用，没有根据测试结果重新训练或调整；History-only 和 NWP-only 使用普通 LSTM 相同的训练协议以及随机种子 `42/2026/3407`，只根据验证集 MSE 早停。

## 2. 输入消融定义

- **完整输入普通 LSTM**：过去24小时功率编码器；未来24小时 NWP、UTC 日历特征和场站 embedding 解码器。
- **History-only**：保留历史功率编码器、UTC 日历和场站 embedding，彻底移除未来 NWP。
- **NWP-only**：移除历史功率编码器及其隐藏状态；解码器从零状态开始，保留未来 NWP、UTC 日历和场站 embedding。

参数量分别为完整输入 `39,245`、History-only `36,173`、NWP-only `22,093`。这是信息通路变化所带来的结构差异，不能称为等参数量实验。

## 3. 三随机种子消融结果

| 变体 | 数据划分/范围 | MAE | RMSE | nRMSE |
|---|---|---:|---:|---:|
| History-only | 验证集整体 | 0.057307 ± 0.000404 | 0.108742 ± 0.000753 | 10.874% ± 0.075% |
| History-only | 测试集整体 | 0.043347 ± 0.000144 | 0.088319 ± 0.000751 | 8.832% ± 0.075% |
| History-only | 测试集活跃时段 | 0.089409 ± 0.001046 | 0.128095 ± 0.001109 | 12.809% ± 0.111% |
| NWP-only | 验证集整体 | 0.037400 ± 0.000591 | 0.077401 ± 0.000430 | 7.740% ± 0.043% |
| NWP-only | 测试集整体 | 0.034300 ± 0.000978 | 0.072061 ± 0.000430 | 7.206% ± 0.043% |
| NWP-only | 测试集活跃时段 | 0.068090 ± 0.000153 | 0.104163 ± 0.000622 | 10.416% ± 0.062% |

相对完整输入普通 LSTM：

- History-only 的测试 MAE/RMSE 分别升高 `32.72%/29.51%`；
- NWP-only 的测试 MAE/RMSE 分别升高 `5.02%/5.67%`。

在该固定模型与训练协议下，历史功率和未来 NWP 都提供了增量预测信息；移除 NWP 的损失明显更大，说明日前任务更依赖预测时可获得的未来天气预报。该结论只涉及模型预测信息，不是气象变量对光伏出力的物理因果效应。

## 4. 配对移动块 Bootstrap

测试集包含91个 UTC 预测日期，每个日期保留三个场站和完整24小时。每次从连续日期块中有放回抽样，两个模型使用相同索引；在每个重采样窗口内先分别重算三个种子的整体指标，再对种子指标求均值。主分析使用7天块、2,000次重复和随机种子 `20260901`；3天与14天块作为敏感性分析。

以下差值均定义为“候选模型 − 参考模型”，负数有利于候选模型：

| 比较 | 指标差值 | 7天块95%区间 | 是否跨0 |
|---|---:|---:|---:|
| 普通 LSTM − XGBoost | MAE +0.001474 | [0.000549, 0.002393] | 否 |
| 普通 LSTM − XGBoost | RMSE −0.000749 | [−0.002865, 0.001653] | **是** |
| Attention-LSTM − 普通 LSTM | MAE +0.001030 | [0.000604, 0.001472] | 否 |
| Attention-LSTM − 普通 LSTM | RMSE +0.000982 | [0.000365, 0.001725] | 否 |
| History-only − 普通 LSTM | MAE +0.010686 | [0.006537, 0.013702] | 否 |
| History-only − 普通 LSTM | RMSE +0.020124 | [0.010303, 0.026353] | 否 |
| NWP-only − 普通 LSTM | MAE +0.001639 | [0.000943, 0.002289] | 否 |
| NWP-only − 普通 LSTM | RMSE +0.003866 | [0.001932, 0.006037] | 否 |

3天和14天敏感性分析没有改变上述跨零判断。由此可作如下有限表述：

1. XGBoost 的测试 MAE 优势在三种块长下均得到支持；
2. 普通 LSTM 的点估计 RMSE 更低，但区间跨0，当前不足以支持其具有稳定 RMSE 优势；
3. Attention-LSTM 的测试 MAE/RMSE 均稳定差于普通 LSTM；
4. 两种输入消融均稳定差于完整输入，支持两类输入具有互补预测价值。

区间跨0不证明两个模型等效。三随机种子标准差描述训练随机性，日期块区间描述有限测试时间窗口的不确定性，两者不能互相替代。

## 5. 分场站、分时距和条件诊断

普通 LSTM 在三个场站的 RMSE 均略低于 XGBoost：Zone 1 为 `0.064325/0.065675`，Zone 2 为 `0.071885/0.072218`，Zone 3 为 `0.068166/0.068782`。但整体日期块区间仍跨0，说明分场站点估计方向一致并不等于跨测试日期的优势已经稳定。

分预测时距结果显示，普通 LSTM 在预测小时2–6的 RMSE 低于 XGBoost，而 XGBoost 在第1小时及第7–24小时多数时距更低。该模式为事后描述，没有逐时距多重比较校正，不应用于选择性宣称某一模型“在长期预测上全面更好”。

高功率阈值由训练集正功率目标的第75百分位确定，为 `0.615911`；测试集选中472个小时。爬坡阈值由训练集绝对相邻功率变化的第90百分位确定，为 `0.210328`；测试集选中437个小时。

| 模型 | 高功率 RMSE | 爬坡区间 RMSE |
|---|---:|---:|
| XGBoost | 0.091291 | 0.133933 |
| 普通 LSTM | 0.092679 | 0.131187 |
| Attention-LSTM | 0.092173 | 0.129061 |
| History-only | 0.123913 | 0.170400 |
| NWP-only | 0.096180 | 0.130510 |

Attention-LSTM 在爬坡区间的描述性 RMSE 最低，但该分组在查看总体测试结果后分析，且未单独计算分组 bootstrap 区间，因此不能据此推翻其总体测试表现较差的结论，也不能声称模型能提前识别爬坡事件或降低调度成本。

## 6. 可复现性与产物

两个消融的六个 checkpoint 均已独立重载，并在完整验证集与测试集上逐点复算。重算预测与保存的显式种子维度数组完全一致；逐种子指标、汇总、早停历史和 `[0,1]` 输出边界均通过检查。

运行命令：

```powershell
python scripts/train_lstm_ablations.py --config configs/day_ahead.yaml
python scripts/run_exploratory_analysis.py --config configs/day_ahead.yaml
```

主要产物：

- `artifacts/lstm_ablations/predictions.npz`

## 7. 结论

完整输入普通 LSTM 的优势主要来自历史功率与未来 NWP 的互补，而未来 NWP 是更关键的预测信息来源。XGBoost 仍具有更稳定的 MAE 优势；普通 LSTM 的 RMSE 点估计最低，但时间块区间不足以支持稳定优势；Attention-LSTM 没有带来总体泛化收益。该证据链比继续增加缺乏可信拓扑的 STGCN 更适合支撑当前项目报告。
