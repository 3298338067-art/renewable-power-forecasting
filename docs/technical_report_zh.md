# 基于历史功率与数值天气预报的光伏日前功率预测

## 技术摘要

本项目构建并审计了一个固定的 24→24 光伏日前点预测任务：在每天 `00:00 UTC`，使用三个场站过去 24 小时功率、此时已经可获得的未来 24 小时 ECMWF 数值天气预报（NWP）、UTC 日历特征和场站标识，预测未来 24 小时归一化功率。数据按时间顺序划分为 `1917/270/273` 个训练、验证和测试样本，所有变换器只在训练集拟合，测试集不参与调参、早停或模型选择。

主要结果不是“某个模型全面获胜”，而是两种误差目标之间存在清晰权衡。XGBoost 取得最低测试 MAE `0.031186 ± 0.000199`；普通 Seq2Seq LSTM 取得最低测试 RMSE 点估计 `0.068195 ± 0.000561`，相对 XGBoost 小幅降低约 `1.1%`。但是按连续 UTC 日期进行的 7 天配对移动块 bootstrap 显示，普通 LSTM 减 XGBoost 的 RMSE 差值为 `−0.000749`，95%区间 `[−0.002865, 0.001653]`，不足以支持稳定 RMSE 优势；MAE 差值为 `+0.001474`，区间 `[0.000549, 0.002393]`，支持 XGBoost 的 MAE 优势。

显式 Bahdanau 时间注意力没有改善测试表现。Attention-LSTM 的测试 MAE/RMSE 均差于普通 LSTM；三种子聚合后的注意力权重几乎等于 `1/24`，未呈现一致的历史时刻偏好。该聚合结果不能排除不同随机种子或个别样本中存在相互抵消的选择性模式。History-only 与 NWP-only 消融均差于完整输入 LSTM，支持两类输入具有互补预测价值；移除 NWP 的损失更大。消融、分组诊断和区间估计是在查看主测试结果后开展的事后探索性分析，只用于解释模型行为，不重新选择主模型。

## 1. XGBoost 保持较低平均误差，LSTM 只显示有限的 RMSE 点估计优势

下表使用统一测试窗口和评价样本。学习模型为三个固定随机种子 `42/2026/3407` 的指标均值 ± 样本标准差；两个持续性模型是确定性基线。

| 模型 | 测试 MAE | 测试 RMSE | 容量 nRMSE | 结果定位 |
|---|---:|---:|---:|---|
| 前一日持续性 | 0.057323 | 0.132836 | 13.284% | 更强的简单基线 |
| 7 日季节性持续性 | 0.068158 | 0.150790 | 15.079% | 较弱基线 |
| XGBoost | **0.031186 ± 0.000199** | 0.068945 ± 0.000303 | 6.894% ± 0.030% | MAE 最低 |
| 普通 LSTM | 0.032660 ± 0.000830 | **0.068195 ± 0.000561** | **6.820% ± 0.056%** | RMSE 点估计最低 |
| Attention-LSTM | 0.033690 ± 0.002231 | 0.069177 ± 0.001315 | 6.918% ± 0.132% | 未超过普通 LSTM |

![五类主模型统一比较](../reports/figures/unified_model_comparison.png)

普通 LSTM 相对前一日持续性将测试 RMSE 降低 `48.66%`，XGBoost 降低 `48.10%`，说明两种学习模型都获得了实质性预测价值。二者之间的差异则明显更小：LSTM 更强调减少少数较大误差，因此 RMSE 略低；XGBoost 在一般时刻的平均绝对误差更低。配对区间进一步表明，当前测试窗口只支持 XGBoost 的 MAE 优势，不支持将 LSTM 的 RMSE 点估计差异推广为稳定优势。

证据来源：[基线指标](../artifacts/baselines/metrics.json)、[XGBoost 指标](../artifacts/xgboost/metrics.json)、[普通 LSTM 指标](../artifacts/lstm/metrics.json)、[Attention-LSTM 指标](../artifacts/attention_lstm/metrics.json)。

## 2. 固定预测任务使模型比较具有可审计性

### 2.1 数据来源与样本范围

数据来自 GEFCom2014 Solar Track，包含澳大利亚同一区域三个相邻光伏场的小时级归一化功率和 12 个 ECMWF NWP 字段。规范原始面板覆盖 `2012-04-01 01:00 UTC` 至 `2014-07-01 00:00 UTC`，共 `59,112` 行；没有缺失值、重复站点—时间记录或非 1 小时间隔。场站精确位置未公开，因此本项目保留 UTC，不做无依据的当地时区换算。

原始数据来自 [GEFCom2014 论文附件](https://doi.org/10.1016/j.ijforecast.2016.02.001)，并由 [IEEE PES 数据共享目录](https://ieee-pes-data-sharing.org/datasets/detail/b1680aa5-a4b8-4423-8760-e509094cacec)收录。来源页没有给出明确再分发许可证，故仓库不包含原始或处理后数据。详细哈希、字段和许可边界见[数据来源记录](data_source_record.md)。

### 2.2 输入、目标与时间切分

对每个预测起点 `t`：

- 编码历史：`t−23` 至 `t` 的 24 小时功率；
- 已知未来协变量：`t+1` 至 `t+24` 的 12 维 NWP 与 4 维 UTC 日历特征；
- 目标：`t+1` 至 `t+24` 的 24 小时功率；
- 输出边界：统一裁剪至 `[0,1]`。

| 划分 | 预测起点日期 | 每站样本 | 三站总样本 |
|---|---|---:|---:|
| 训练集 | 2012-04-02—2013-12-31 | 639 | 1,917 |
| 验证集 | 2014-01-01—2014-03-31 | 90 | 270 |
| 测试集 | 2014-04-01—2014-06-30 | 91 | 273 |

累计 NWP 字段 `VAR169/175/178/228` 在每个场站—预报日内转为逐小时增量，负增量先审计后按非负物理边界裁剪。NWP 标准化均值和标准差只由训练集估计，再应用到验证和测试集。未来真实功率从不进入模型输入，验证和测试标签也不参与预处理参数拟合。

### 2.3 指标定义

- `MAE = mean(|y − ŷ|)`：衡量平均绝对误差，对少数大误差相对不敏感；
- `RMSE = sqrt(mean((y − ŷ)^2))`：对较大误差施加更高惩罚；
- `容量 nRMSE = 100 × RMSE`：由于目标接近标幺功率，单位为标称容量百分比；
- 活跃时段指标：在未来输入中的 `VAR169` 逐小时辐照增量 `> 0` 的位置重新计算 MAE/RMSE。掩码不读取未来真实功率。

完整 24 小时指标和活跃时段指标同时保留，避免大量零功率时刻掩盖有效辐照条件下的误差。

## 3. 模型和验证协议只改变被检验的因素

### 3.1 持续性模型

前一日持续性使用目标时刻 24 小时前的同站功率；7 日季节性持续性使用 7 天前同站同小时功率。两者不训练参数，用来判断复杂模型是否提供超过简单重复规则的价值。

### 3.2 XGBoost

每个目标小时转换为一行监督样本，共 44 个特征：24 个历史功率滞后、目标小时的 12 个 NWP、4 个周期日历特征、预测时距以及三个场站 one-hot。三个预先固定候选只按验证 RMSE 比较，选出 `max_depth=6`、`learning_rate=0.03`、最多 800 棵树的方案后，才读取测试集并用三个种子重训。

### 3.3 普通 Seq2Seq LSTM

单层 64 维编码器读取 `[B,24,1]` 历史功率；单层解码器读取未来 NWP、日历特征和 4 维场站 embedding。编码器最终隐状态和记忆状态初始化解码器，模型不使用 teacher forcing。固定使用 Adam、学习率 `1e-3`、weight decay `1e-5`、batch size 128、MSE 损失和梯度范数裁剪 1.0。每个种子最多 100 epoch，只按验证 MSE 早停并恢复最佳权重。

### 3.4 Temporal-Attention LSTM

Attention-LSTM 只在普通 LSTM 上增加 Bahdanau 加性时间注意力：每个未来时刻以上一解码隐藏状态为 query，对 24 个历史编码状态评分并在历史时间维 softmax，再将 context 与当前未来协变量拼接。除结构新增外，数据、隐藏维度、优化器、训练预算、早停、种子和评估代码保持一致。普通 LSTM 与 Attention-LSTM 分别有 `39,245` 和 `63,949` 个可训练参数，因此这是训练协议公平、但并非参数量相等的结构比较。

## 5. 日期块区间改变了点估计的解释，而不是制造新的“冠军”

小时误差具有时间相关性，同一天三个场站也不是独立样本。因此主不确定性分析按连续 7 天 UTC 预测日期块重采样，每个被抽中的日期同时保留三个场站和完整 24 小时，执行 2,000 次重复；3 天和 14 天块用于敏感性检查。对每个重采样窗口，先分别使用三个种子的预测重算完整窗口 MAE/RMSE，再对三个种子的指标求均值；模型差值由两个种子均值指标相减得到。这与主表“先算逐种子指标、再报告种子均值”的聚合对象一致，而不是先平均三组预测后计算一个集成指标，也不是对每日 RMSE 作简单平均。

差值定义为“候选模型减参考模型”：

| 比较 | 指标差值 | 95%区间 | 解释 |
|---|---:|---:|---|
| 普通 LSTM − XGBoost | MAE `+0.001474` | `[0.000549, 0.002393]` | 支持 XGBoost 较低 MAE |
| 普通 LSTM − XGBoost | RMSE `−0.000749` | `[−0.002865, 0.001653]` | 区间跨 0，稳定优势未建立 |
| Attention-LSTM − 普通 LSTM | MAE `+0.001030` | `[0.000604, 0.001472]` | Attention 更差 |
| Attention-LSTM − 普通 LSTM | RMSE `+0.000982` | `[0.000365, 0.001725]` | Attention 更差 |
| History-only − 普通 LSTM | RMSE `+0.020124` | `[0.010303, 0.026353]` | 完整输入更好 |
| NWP-only − 普通 LSTM | RMSE `+0.003866` | `[0.001932, 0.006037]` | 完整输入更好 |

区间跨 0 只表示现有窗口不足以建立方向稳定的差异，不等于证明两个模型完全等效。区间来自测试日期的条件性重采样，也不能覆盖训练随机性、其他季节或其他场站造成的全部不确定性。完整结果见[统一探索性评估](exploratory_analysis_results.md)和[保存的分析指标](../artifacts/exploratory_analysis/metrics.json)。

## 6. 注意力负结果揭示了复杂度与有效信息之间的差别

Attention-LSTM 在验证集整体 RMSE 上比普通 LSTM 低 `0.80%`，因此按预先固定的验证规则保留；但测试整体 RMSE/MAE 分别高 `1.44%/3.15%`，且种子间方差更大。配对日期块区间也支持其总体测试表现较差。

理论均匀权重为 `1/24 = 0.0416667`。当前持久化的三种子平均测试权重张量在全部测试样本、预测时距和历史位置上的范围仅为 `0.0416602–0.0416828`，该聚合张量的归一化熵约为 `1.0000`。因此，聚合后的注意力权重近似均匀，未呈现一致的历史时刻偏好。由于仓库没有保存逐种子的注意力权重张量，该证据不能排除不同种子或个别样本中的选择性模式在聚合时相互抵消，也不能推出模型在所有样本上都没有时间选择性。

![Attention-LSTM 平均注意力权重](../reports/figures/attention_lstm_weights_heatmap.png)

因此本项目把**总体预测性能**记录为有价值的负结果：在固定 24→24 任务和训练协议下，增加该时间注意力没有提供稳定预测增益。权重审计只支持“聚合权重近似均匀”，不能证明不存在样本级或种子级的选择性；注意力权重也只能描述模型内部权重分配，不能解释为历史时刻的因果重要性。

## 7. 输入消融支持互补预测信息，NWP 是更关键的输入组

消融沿用普通 LSTM 的优化器、早停、随机种子、数据切分和评价代码，只改变输入：

- History-only：保留过去功率、UTC 日历和场站 embedding，移除全部未来 NWP；
- NWP-only：保留未来 NWP、UTC 日历和场站 embedding，移除历史编码器和历史派生状态。

| 输入方案 | 测试 MAE | 测试 RMSE | 相对完整输入 RMSE 变化 |
|---|---:|---:|---:|
| 完整输入普通 LSTM | 0.032660 | 0.068195 | — |
| History-only | 0.043347 | 0.088319 | +29.51% |
| NWP-only | 0.034300 | 0.072061 | +5.67% |

两种消融的 RMSE 差值区间都完全高于 0，支持历史功率与未来 NWP 在该模型中提供互补预测信息。History-only 的损失远大于 NWP-only，说明 NWP 是更关键的输入组。该结果描述输入对固定模型预测的贡献，不证明气象变量对真实发电量的物理因果效应。

## 8. 局限性、失败模式与稳健性边界

1. **外部有效性有限。** 测试期只有 2014 年 4–6 月，且只有三个未公开位置的相邻场站；不能直接外推到其他季节和地区。
2. **不确定性覆盖不完整。** 日期块 bootstrap 处理测试日期相关性，但固定了训练结果；三随机种子标准差只能粗略反映优化随机性。
3. **确定性预测范围有限。** 项目不输出分位数或预测区间，不能满足风险约束调度对概率信息的需求。
4. **没有成本验证。** 高功率和爬坡分组是查看总体结果后的描述性诊断，不能声称模型能提前识别事件或降低调度成本。
5. **模型解释不是因果解释。** XGBoost 内置特征重要性会在相关特征间分摊，注意力权重也不等于特征贡献。
6. **复杂模型未必合适。** Attention-LSTM 增加 `62.95%` 参数却没有稳定收益；缺少可信空间拓扑时，增加 STGCN 只会提升复杂度而不提升证据质量。
7. **数据分发受限。** 原始数据未给出明确再分发许可证，第三方复现需要自行从官方来源下载。

## 9. 复现与审计路径

在仓库根目录执行：

```powershell
python scripts/check_environment.py
python -m pytest -q
python scripts/preprocess_data.py --config configs/day_ahead.yaml
python scripts/evaluate_baselines.py --config configs/day_ahead.yaml
python scripts/train_xgboost.py --config configs/day_ahead.yaml
python scripts/train_lstm.py --config configs/day_ahead.yaml
python scripts/train_attention_lstm.py --config configs/day_ahead.yaml
python scripts/train_lstm_ablations.py --config configs/day_ahead.yaml
python scripts/run_exploratory_analysis.py --config configs/day_ahead.yaml
```

自动化测试覆盖输入/输出形状、时间顺序、未知场站、目标泄漏、训练集专用标准化、注意力 softmax 维度、梯度连通、早停、checkpoint 重载和端到端产物合同。正式 LSTM、Attention-LSTM 与消融 checkpoint 另行完成完整验证/测试集重载、预测重算、均值与标准差重算以及 `[0,1]` 输出边界检查。

复现说明、依赖和数据目录见仓库 [README](../README.md)。代码许可证仍需由项目所有者确认；首个提交完成后还需执行干净克隆检查。

## 10. 证据支持的后续方向

1. 优先完成公开仓库的代码许可证、干净克隆复现和引用元数据，而不是增加新模型。
2. 若业务决策关注风险，下一步应扩展为分位数或概率预测，并使用校准度与区间评分，而不是只比较点预测 RMSE。
3. 若获得场站坐标、距离或电网拓扑，再评估图时空模型；没有可信邻接关系时不加入 STGCN。
4. 在独立季节或新场站上做外部验证，检验 XGBoost MAE 优势与 LSTM RMSE 权衡能否复现。
5. 若继续模型解释，采用配对重采样的 permutation/SHAP 稳定性分析，并继续明确“模型贡献不等于因果作用”。
