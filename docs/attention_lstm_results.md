# Temporal-Attention LSTM 模型评估记录

## 1. 实验目的与公平对照

本实验在普通 Seq2Seq LSTM 上只增加 Bahdanau 加性时间注意力，用于检验显式聚合 24 个历史编码状态能否稳定改善日前光伏功率预测。数据划分、历史功率、未来 NWP、UTC 日历特征、场站 embedding、隐藏维度、优化器、学习率、weight decay、batch size、训练上限、早停规则、梯度裁剪、输出裁剪、随机种子和评价代码均与普通 LSTM 相同。

每个未来时刻使用上一时刻的解码器隐藏状态作为 query，对 24 个历史编码状态计算分数，并在历史时刻维度执行 softmax。得到的 context 与该未来时刻的 NWP、UTC 日历特征和场站 embedding 拼接后输入解码器。模型不读取未来真实功率，不使用 teacher forcing。因为全部 24 个历史时刻在预测起点已经可用，所以历史注意力不需要因果 mask。

普通 LSTM 有 `39,245` 个可训练参数，Attention-LSTM 有 `63,949` 个，增加 `24,704` 个（`62.95%`）。这是结构变化带来的正常差异，因此不能把本实验理解为等参数量比较。

## 2. 模型选择规则

结构和超参数在测试前固定，没有搜索 Attention 候选。每个随机种子只根据验证集 MSE 早停并恢复最佳 checkpoint；模型层面的首要判断指标是三随机种子验证集整体 RMSE，MAE 同时报告。测试集没有参与训练、早停或保留判断。

Attention-LSTM 的验证集整体 RMSE 为 `0.075389`，较普通 LSTM 的 `0.075995` 降低 `0.80%`；验证集整体 MAE 为 `0.036516`，较普通 LSTM 的 `0.037012` 降低 `1.34%`。因此按照预先约定的验证集规则，Attention-LSTM 作为有效实验结果保留。

“保留”只表示验证集首要指标通过，不表示模型在最终测试集上优于普通 LSTM。

| 数据划分 | 评价范围 | MAE | RMSE | 容量归一化 nRMSE |
|---|---|---:|---:|---:|

## 4. 与现有模型的比较

### 4.1 与普通 LSTM

| 数据划分 | 评价范围 | Attention-LSTM 相对 RMSE 变化 | Attention-LSTM 相对 MAE 变化 |
|---|---|---:|---:|
| 验证集 | 整体 | 降低 0.80% | 降低 1.34% |
| 验证集 | 辐照活跃时段 | 降低 0.80% | 降低 1.76% |
| 测试集 | 整体 | **升高 1.44%** | **升高 3.15%** |
| 测试集 | 辐照活跃时段 | **升高 1.31%** | **升高 0.70%** |

验证集上的小幅改善没有延续到测试集，且 Attention-LSTM 的测试方差也更大。因此，新增注意力机制没有带来稳定的泛化收益。普通 LSTM 仍保持当前最低的测试集整体 RMSE `0.068195`。

### 4.2 与 XGBoost 和持续性基线

Attention-LSTM 的测试集整体 RMSE/MAE 均差于 XGBoost：RMSE 高 `0.34%`，MAE 高 `8.03%`。在辐照活跃时段，Attention-LSTM 的 RMSE 仅比 XGBoost 低 `0.074%`，可视为非常接近，但 MAE 仍高 `1.24%`。XGBoost 继续保持当前最低的测试集整体 MAE `0.031186`。

相对前一日持续性基线，Attention-LSTM 的测试集整体 RMSE 降低 `47.92%`，说明模型本身有效，但这不能证明注意力优于更简单的普通 LSTM。

## 5. 注意力权重审计

所有权重均为有限非负数，并且每个未来时刻的 24 个历史权重之和在数值容差内等于 1；softmax 确实沿历史时刻维度执行，注意力参数也能从预测损失获得非零梯度。

不过，当前持久化的是三随机种子平均后的权重张量。该张量在全部测试样本、预测时距和历史位置上的权重几乎完全均匀：理论均匀值为 `1/24 = 0.0416667`，实际范围仅为 `0.0416602–0.0416828`，相对均匀值的平均绝对偏差为 `3.95×10⁻⁶`，归一化熵约为 `1.0000`。

因此，热力图只能解释为“三种子聚合后的权重未呈现一致的历史时刻偏好”。仓库没有保存逐种子的注意力权重张量，这项审计不能排除不同种子或个别样本中的选择性模式在聚合时相互抵消，也不能证明模型对每个样本都近似等权。注意力权重是描述性模型量，不是因果特征重要性。

## 6. 复现与独立核验

运行正式实验：

```powershell
python scripts/train_attention_lstm.py --config configs/day_ahead.yaml
```

已完成以下核验：

1. 三个 checkpoint 均能严格加载，并在完整验证集和测试集上复算出与 `metrics.json` 一致的逐种子指标；
2. 重新汇总的均值和样本标准差与正式结果一致；
3. checkpoint 中的最佳 epoch、最佳验证损失、训练长度和早停状态相互一致；
4. 重算的三种子均值预测与保存的 NPZ 数组一致；
5. 注意力权重形状为 `[样本数, 24, 24]`，有限、非负且沿历史维度归一化；
6. 模型测试覆盖输出形状、归一化维度、梯度连通、无未来目标泄漏、未来协变量的时间顺序和 checkpoint 重载。

## 7. 结论

本实验得到的是一个应当保留的总体性能负结果：Attention-LSTM 按预先规定的验证集 RMSE 规则通过，但在最终测试集的 RMSE 和 MAE 上都没有超过普通 LSTM；三种子聚合权重也近似均匀。不能表述为“Attention-LSTM 提升了模型性能”或“注意力发现了关键历史时刻”，也不能由聚合权重进一步断言每个种子和样本都缺乏选择性。当前证据支持的结论是：**显式 Bahdanau 时间注意力在该固定 24→24 任务和训练协议下没有带来稳定增益。**
